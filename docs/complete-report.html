🤖 KAIROS - 持久助手模式

源码位置： src/assistant/ | 编译开关： feature('KAIROS')

核心功能

  • 跨会话持久运行 - 通过 assistant: true 激活，会话状态持久化到磁盘
  • 每日日志 - 自动在 <autoMemPath>/logs/YYYY/MM/YYYY-MM-DD.md 记录工作日志
  • 自动做梦 (Dream) - 距上次整合超 24 小时且有 5+ 新会话时，后台自动启动记忆整合
  • 四阶段流程 - Orient → Gather → Consolidate → Prune
  • 锁机制 - .consolidate-lock 文件 + PID 存活检查
  • 主动模式 (Proactive) - 没人说话时自己找活干，没活就调用 SleepTool
  • 后台任务 - 命令超 15 秒自动丢后台，支持永久 cron 任务

👥 COORDINATOR - 多 Agent 编排

源码位置： src/coordinator/ | 编译开关： feature('COORDINATOR_MODE')

架构设计

  • 角色分离 - Coordinator 只有三个工具：派活 (Agent)、通信 (SendMessage)、停工 (Shutdown)
  • Worker 机制 - Worker 在独立子进程中运行，各自拥有完整工具集
  • 核心铁律 - "禁止甩锅式委派"——不能把不清楚的需求直接丢给 Worker
  • 任务追踪 - 基于文件的共享任务列表 (~/.claude/tasks/)

📖 工具使用详解

以下是所有核心工具的详细使用说明，包括命令语法、参数和示例。

1. 文件操作工具

Read (文件读取)

/Read <file_path> [options]

参数:
  file_path   string  ✅  文件绝对路径
  limit       number  ❌  最大行数 (默认 2000)
  offset      number  ❌  起始行号 (默认 0)
  pages       string  ❌  PDF 页码范围 (如 "1-5")

示例:
/Read /Users/heal/src/app.ts
/Read /path/to/doc.pdf --pages "3-5"
/Read notebook.ipynb

Edit (文件编辑)

/Edit <file_path> --old_string "原字符串" --new_string "新字符串" [options]

参数:
  file_path    string  ✅  文件绝对路径
  old_string   string  ✅  要替换的原始字符串
  new_string   string  ✅  替换后的新字符串
  replace_all  boolean ❌  替换所有匹配 (默认 false)

示例:
/Edit src/app.ts --old "function old() {}" --new "function new() {}"
/Edit config.ts --old "DEBUG=true" --new "DEBUG=false" --replace_all true

Write (文件写入)

/Write <file_path> --content "<文件内容>"

参数:
  file_path  string  ✅  文件绝对路径
  content    string  ✅  完整文件内容

示例:
/Write src/utils.ts --content "export function helper() { return 42; }"

Glob (文件搜索)

/Glob --pattern "<glob 模式>" [--path "<目录>"]

参数:
  pattern  string  ✅  glob 模式 (如 **/*.ts)
  path     string  ❌  搜索目录 (默认 cwd)

示例:
/Glob --pattern "**/*.tsx"
/Glob --pattern "src/**/*.ts" --path "/Users/heal/project"

Grep (内容搜索)

/Grep --pattern "<正则表达式>" [options]

参数:
  pattern      string  ✅  正则表达式
  path         string  ❌  搜索目录
  glob         string  ❌  文件模式 (*.ts)
  type         string  ❌  文件类型 (js/py/rust)
  -n           boolean ❌  显示行号 (默认 true)
  -i           boolean ❌  忽略大小写
  output_mode  string  ❌  content/files_with_matches/count
  -A/-B/-C     number  ❌  上下文行数

示例:
/Grep --pattern "useState" --type ts
/Grep --pattern "TODO" -A 2 -B 2 --output_mode content

2. 命令行执行工具

Bash

/Bash --command "<命令>" [options]

参数:
  command          string  ✅  要执行的命令

示例:

⚙️ 配置机制详解

配置文件优先级

1. 管理设置 (最高优先级) - 企业/团队策略
2. 系统设置 - /etc/claude-code/config.json
3. 用户设置 - ~/.claude/settings.json
4. 项目设置 - .claude.local.json
5. 命令行参数 (可覆盖所有)
