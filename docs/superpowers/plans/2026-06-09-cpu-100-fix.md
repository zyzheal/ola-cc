# CPU 100% Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix CPU 100% caused by unbounded graph algorithms, full AST scans, and tool over-exposure.

**Architecture:** Add timeout/limit protection to three trigger sources: (1) pageRank/classifyRoles get timeoutMs params, (2) grok_architecture gets overall deadline, (3) AST scan gets file count cap + timeout. Fix tool exposure by removing codegraph/grok from ALWAYS_INCLUDE_TOOLS.

**Tech Stack:** TypeScript, Bun test runner, GraphEngine, GrokManager, runAgent.ts, toolRanker.ts

**Root Cause Doc:** `docs/analysis/pid-30087-cpu-100-root-cause.md`
