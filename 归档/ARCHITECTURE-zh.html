03 核心子系统
⚙
QueryEngine
src/QueryEngine.ts · 约 4.6 万行
系统核心。管理完整的 LLM 交互循环：向 Anthropic 发起流式 API 调用、工具调用分发与结果注入、思考模式 Token 处理、退避重试、Token 计数以及上下文窗口管理。所有工具调用均经过此处。
流式调用 工具循环 重试 思考模式
◈
REPL + Ink Renderer
src/screens/REPL.tsx · src/ink/
基于 React + Ink 构建的全屏终端 UI。自定义 Yoga 布局引擎、备用屏幕管理、基于差异的终端补丁渲染，以及 patchStderr 防止 UI 被污染。REPL 是主要的交互界面——React 组件树渲染到终端字符格。
React Ink Yoga 备用屏幕
▣
Tool System
src/tools/ · 约 40 个工具 · src/Tool.ts 约 2.9 万行
Claude Code 的每项能力都是独立的工具模块，包含 Zod 输入模式、权限模型和执行函数。工具注册到中央注册表，以 JSON 函数定义的形式暴露给 LLM。执行结果流式返回查询循环。
Zod 注册表 权限控制
⬡
MCP Integration
src/services/mcp/
通过 stdio 或 SSE 连接模型上下文协议服务器。动态发现服务器工具并将其作为一等公民工具暴露给 Claude Code。支持多服务器配置、OAuth 认证服务器以及工具定义热重载。
stdio SSE 动态发现
⇄
Bridge System
src/bridge/
连接 IDE 扩展（VS Code、JetBrains）与运行中 CLI 进程的双向 IPC 层。JWT 认证的消息协议，带权限回调、会话管理，以及供 IDE 面板嵌入的 REPL 桥接。
IPC JWT VS Code JetBrains
⛭
Permission System
src/hooks/toolPermission/
每次工具调用的拦截器。根据配置模式解析权限：交互式会话中提示用户确认，绕过模式下自动批准，计划模式下强制只读限制。支持按工具和按路径的允许/拒绝规则。
默认 计划 绕过 自动
⊕
Coordinator / Agent Swarm
src/coordinator/
编排多智能体工作流。AgentTool 派生子智能体；TeamCreateTool 管理并行智能体团队。协调器追踪任务归属、智能体间消息传递（SendMessageTool），并将结果汇总回根会话。
并行 子智能体 团队
◉
Memory System
src/memdir/ · src/services/extractMemories/
存储在 memdir 中的跨会话持久记忆。会话结束后通过 LLM 自动提取重要事实。团队记忆同步在协作者之间共享知识。/memory 命令提供用户侧管理界面。
持久化 自动提取 团队同步
⚑
Feature Flags
bun:bundle · src/services/analytics/
通过 Bun bundle 标志实现编译期死代码消除，将非活跃功能从二进制文件中完全剔除。GrowthBook 运行时标志支持灰度发布。主要标志：PROACTIVE、KAIROS、BRIDGE_MODE、DAEMON、VOICE_MODE、AGENT_TRIGGERS、MONITOR_TOOL。
编译期 GrowthBook Tree-shake
04 启动顺序
01
并行预取
在重型模块导入前触发副作用： startMdmRawRead() startKeychainPrefetch() API 预连接 — 与模块求值并行执行
02
命令行解析
Commander.js 解析 argv — 标志、子命令、-p 打印模式。 确定交互式还是非交互式会话。
03
配置加载
读取 ~/.claude.json 全局配置、主题、OAuth token。 GrowthBook 功能开关初始化，MDM 托管配置解析。
04
Ink 挂载
createRoot() 初始化 React/Ink 渲染器。 备用屏幕激活，欢迎界面/设置界面渲染。
05
初始化界面
信任对话框、新手引导、必要时 OAuth 登录。 验证组织约束（validateForceLoginOrg）。
06
MCP + 钩子
并行建立 MCP 服务器连接。 SessionStart 钩子触发，从 cwd 层级加载 CLAUDE.md 文件。
07
REPL 启动
launchRepl() 渲染完整 REPL。 若带 -p 标志：非交互式查询 → stdout → 退出。 否则：交互式会话开始，等待用户输入。
05 权限模式
default
每次工具执行前提示用户确认。文件读取自动批准；写入、Shell、网络请求需明确 yes/no/always。
plan
只读模式——允许文件读取和搜索，所有写入和 Shell 命令被阻止。用于提交前的安全探索。
bypassPermissions
所有工具无需提示自动批准。用于自动化流水线和 CI。需要显式启用标志。
auto
基于操作风险评分和信任上下文的启发式自动批准。仅对高风险操作弹出提示。

07 技术栈
类别 技术 职责
运行时 Bun 高速 JS/TS 运行时 + 打包器。bun:bundle 功能标志支持编译期死代码消除。
语言 TypeScript（严格模式） 约 1,900 个文件、512K+ 行代码的端到端类型安全。
终端 UI React + Ink 通过 Yoga 布局将 React 组件树渲染到终端字符格。自定义差异渲染器实现高效更新。
命令行解析 Commander.js 带额外类型的参数解析。处理子命令、标志、打印模式。
Schema 验证 Zod v4 工具输入、配置文件、API 响应的运行时校验。为 LLM 工具定义生成 JSON Schema。
代码搜索 ripgrep 内置 ripgrep 二进制文件，用于在大型代码库中快速进行正则搜索。
协议 MCP SDK + LSP 外部工具服务器的模型上下文协议。LSP 提供语言智能（悬停、诊断、引用）。
API 客户端 Anthropic SDK 流式 API 客户端。处理 SSE、Token 计数、重试和模型路由。
遥测 OpenTelemetry + gRPC 性能监控的链路追踪导出。延迟加载以避免冷启动开销。
功能开关 GrowthBook 灰度发布的运行时功能开关。与编译期 Bun 标志配合使用。
认证 OAuth 2.0 + JWT + Keychain claude.ai OAuth 流程。macOS Keychain 存储 token。JWT 用于 Bridge IPC 认证。
